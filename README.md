# SiLomba

SiLomba is a platform for managing contests, teams, and applications. This project is built using Laravel (migrated from Node.js/Express) and provides a robust API and web interface for all your contest management needs.

## Features

- **User Management:** Complete authentication and user roles.
- **Contest Management:** Create, update, and manage various contests.
- **Team Management:** Form teams and manage members for group competitions.
- **Applications:** Handle submissions and applications for contests seamlessly.

## Getting Started

1. Clone the repository: `git clone https://github.com/FaizAlfaRizqy/SiLomba.git`
2. Install dependencies: `composer install` and `npm install`
3. Copy `.env.example` to `.env` and configure your database.
4. Generate app key: `php artisan key:generate`
5. Run migrations: `php artisan migrate`
6. Start the development server: `php artisan serve`
